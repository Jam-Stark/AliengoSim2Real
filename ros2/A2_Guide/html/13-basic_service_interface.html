底层服务接口

更新时间：2026-05-06 14:55:44

底层通信提供了用户端PC（PC2/外部 PC）与机器人之间的数据交互功能。底层通信采用 DDS 协议。

  • 订阅话题 rt/lowstate(类型: unitree_hg::msg::dds_::LowState_) 获取 A2 当前状态。

  • 发布话题 rt/lowcmd(类型: unitree_hg::msg::dds_::LowCmd_) 控制全身关节电机、电池等设备。

温馨提示

要使用底层服务接口控制A2，需要先关闭Unitree内置的运动控制服务。当前的运动控制服务名称为：ai_sports。您可以使用运控切换服务接口或App关闭服务。

底层控制指令

用户可通过发布 DDS 话题 “rt/lowcmd” 来发送电机、电池、自动充电、电机电源开关的控制指令。

module unitree_hg {
  module msg {
    module dds_ {
      struct LowCmd_ {
          octet mode_pr;                                          //命令模式位。
          octet mode_machine;                                     //命令机型位。
          unitree_hg::msg::dds_::MotorCmd_ motor_cmd[35];         //电机控制命令数据。
          unsigned long reserve[4];                               //保留，目前不用。
          unsigned long crc;                                      //CRC32校验。
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明：

  • mode_pr：命令模式位。可以设置lowstate中关于 特殊关节 是按宇树算法处理，还是原始数据。（0：设置为宇树算法处理。1：原始数据，用户需自行处理。无特殊关节数据时，此位数据无效。）
  • mode_machine：命令机型位。必须和lowstate中mode_machine对齐，否则不响应控制命令。
  • motor_cmd：电机控制命令数据。
  • reserve：保留。
  • crc：CRC32校验。

其中，电机数据的格式如下：

module unitree_hg {
  module msg {
    module dds_ {
      struct MotorCmd_ {
          octet mode;                                                 //电机控制模式  STOP模式->0x00 ; FOC模式->0x01
          float q;                                                    //关节目标位置
          float dq;                                                   //关节目标速度
          float tau;                                                  //关节目标力矩
          float kp;                                                   //关节刚度系数
          float kd;                                                   //关节阻尼系数
          unsigned long reserve;                                      //保留，目前不用。
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明

  • mode：电机控制模式。0x00=待机模式；0x01=FOC模式。
  • q：目标位置
  • dq：目标速度
  • tau：前馈力矩
  • kp：刚度系数
  • kd：阻尼系数
  • reserve：保留

关于PD控制器

关节电机作为一个高度集成的动力单元，其内部已经封装了电机底层的控制算法。作为用户，只需要给关节电机发送相关的命令，电机就能完成从接收命令到关节力矩输出的全部工作。

对于电机的底层控制算法，唯一需要的控制目标就是输出力矩。可是对于机器人，我们通常需要给关节设定位置、速度和力矩。这时就需要对关节电机进行混合控制。

宇树科技的关节电机包含如下 5 个控制指令：

  1. 前馈力矩：tautautau
  2. 期望角度位置：qdesq_{des}qdes​
  3. 期望角速度：dqdesdq_{des}dqdes​
  4. 位置刚度：kpkpkp
  5. 阻尼系数：kdkdkd

在关节电机的混合控制中，使用 PD 控制器将电机在输出位置的偏差反馈到力矩输出上：

τ=tau+kp∗(qdes−q)+kd∗(dqdes−dq)τ=tau+kp∗(q_{des} −q)+kd∗(dq_{des} −dq) τ=tau+kp∗(qdes​−q)+kd∗(dqdes​−dq)

上式中:

  • τττ 为电机转子的期望输出力矩，单位为N.m
  • tau 为电机转子的前馈力矩，单位为N.m
  • qdesq_{des}qdes​ 为电机转子期望的角度位置，单位为rad
  • qqq 为电机转子当前的角度位置，单位为rad
  • dqdesdq_{des}dqdes​ 为电机转子期望的转子角速度。单位为rad/s
  • dqdqdq 为电机转子当前的转子角速度。单位为rad/s
  • kpkpkp 为电机位置误差比例系数，也可以看作刚度系数
  • kdkdkd 为电机速度误差比例系数，也可以看作阻尼系数

机器人身上的关节电机指令会经过底层服务进行二次分发处理，不需要考虑减速比。上文提到的角度与速度均为输出侧数据。

底层状态数据

用户可通过订阅DDS 话题 “rt/lowstate” 来获取电机、电池、IMU等数据。

module unitree_hg {
  module msg {
    module dds_ {
    struct LowState_ {
      unsigned long version[2];                                   //保留，目前不用。
      octet mode_pr;                                              //状态模式位，默认是0。表示当前 特殊关节 数据是宇树算法处理，还是原始数据。（0：宇树算法处理。1：原始数据，用户需自行处理。无特殊关节数据时，此位数据无效。）
      octet mode_machine;                                         //表示当前是那种机型
      unsigned long tick;                                         //1ms计时，按1ms递增。
      unitree_hg::msg::dds_::IMUState_ imu_state;                 //IMU数据。
      unitree_hg::msg::dds_::MotorState_ motor_state[35];         //电机数据。
      octet wireless_remote[40];                                  //宇树实体遥控器原始数据。
      unsigned long reserve[4];                                   //保留，目前不用。
      unsigned long crc;                                          //CRC32校验。
    };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明

  • version：保留
  • mode_pr：状态模式位。
  • mode_machine：状态机型位。
  • tick：时间。从Basic Service启动开始以1ms为单位进行计时的值。
  • imu_state：IMU数据。
  • motor_state：电机数据。
  • wireless_remote：遥控器数据。
  • reserve：保留。
  • crc：CRC32校验。

其中，IMU反馈数据如下：

module unitree_hg {
  module msg {
    module dds_ {
      struct IMUState_ {
          float quaternion[4];                    //四元数数据（0->w，1->x，2->y，3->z）。
          float gyroscope[3];                     //角速度数据（0->x，1->y，2->z）。
          float accelerometer[3];                 //加速度数据（0->x，1->y，2->z）。
          float rpy[3];                           //欧拉角数据（0->roll，1->pitch，2->yaw）。
          short temperature;                      //温度数据。
      
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明

  • quaternion：四元数，描述机器狗姿态在三维空间中的旋转姿态。
  • gyroscope：角速度，描述机器狗转动的速度。
  • accelerometer：加速度，描述机器狗在空间中各个方向的速度变化率。
  • rpy：欧拉角，使用三个角度（偏航、俯仰、滚转）描述机器狗在三维空间中的旋转姿态。
  • temperature：IMU传感器温度。

电机反馈数据如下：

module unitree_hg {
  module msg {
    module dds_ {
      struct MotorState_ {
          octet mode;                         //电机当前模式。
          float q;                            //关节反馈位置数据，默认为弧度值。
          float dq;                           //关节反馈速度数据。
          float ddq;                          //关节反馈加速度数据。
          float tau_est;                      //关节反馈力矩数据。
          short temperature[2];               //温度数据。机型不同电机型号不同，此位数据不同，需参考实际情况。
          float vol;                          //电机端电压数据 。 机型不同电机型号不同，此位数据不同，需参考实际情况。
          unsigned long sensor[2];            //扩展传感器数据 机型不同电机型号不同，此位数据不同，需参考实际情况。。
          unsigned long motorstate;           //电机状态数据。机型不同电机型号不同，此位数据不同，需参考实际情况。
          unsigned long reserve[4];           //保留位（ 0->电机总丢包，1->电机通信频率， 2->电机型号，3->电机警告）。
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明

  • mode：电机控制模式。0x00=待机模式；0x01=FOC模式。
  • q：当前位置
  • dq：当前速度
  • ddq：当前加速度
  • tau_est：当前输出力矩
  • temperature：当前温度
  • sensor：扩展传感器数据
  • motorstate：电机状态数据
  • reserve：反馈数组
    • reserve[0]：电机累计丢包数
    • reserve[1]：电机通信频率
    • reserve[2]：电机型号
    • reserve[3]：电机当前警告

主板状态信息

用户可通过订阅DDS话题 “rt/lf/mainboardstate” 来获取风扇转速、温度数据、电压电流数据与状态信息等数据。

module unitree_hg {
  module msg {
    module dds_ {
      struct MainBoardState_ {
        unsigned short      fan_state[6];         //风扇转速。
        short               temperature[6];       //温度数据（ 0->主板温度，单位：℃。1->主电源温度，范围：-20-85，单位：℃ 。2->主板温度2，单位：℃。3->主板温度3，单位：℃。4->主板温度4，单位：℃）。
        float               value[6];             //电压电流数据（ 0->电池电压，单位：V。 1->电机电压，单位：V。 2->电机电流，单位：A。 ）。
        unsigned long       state[6];             //(0->机器总状态信息。)
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明（此处有疑惑，主板传感器123分别对应？电机电压具体是？）

  • fan_state：风扇转速
  • temperature：温度数据
    • temperature[0]：主板传感器1温度，单位℃
    • temperature[1]：主电源温度，范围-20~85，单位℃
    • temperature[2]：主板传感器2温度，单位℃
    • temperature[3]：主板传感器3温度，单位℃
  • value：电压电流数据
    • value[0]：电池电压，单位：V
    • value[1]：电机电压，单位：V
    • value[2]：电机电流，单位：A
  • state：总状态信息（报错信息）

电池状态信息

用户可通过订阅DDS话题 “lf/bmsstate”（②号电池） 与 “lf/secondary_bmsstate”（①号电池）来获取风扇转速、温度数据、电压电流数据与状态信息等数据。

module unitree_hg {
  module msg {
    module dds_ {
      struct BmsState_ {
        octet               version_high;         // 电池软件版本高位
        octet               version_low;          // 电池软件版本低位
        octet               fn;                   // 数据帧型号
        unsigned short      cell_vol[40];         // 单节电池电压。
        unsigned long       bmsvoltage[3];        // 电压信息，（ 0->bat_voltage， 单位：mV , 1->pack_voltage，单位：mV ）。
        long                current;              // 充放电电流，单位：mA。
        octet               soc;                  // 电量，数值范围（0-100%）。
        octet               soh;                  // 电池健康状态 ，数值范围（0-100%）。
        short               temperature[12];      // 温度。
        unsigned short      cycle;                // 循环数
        unsigned short      manufacturer_date;    // 时间
        unsigned long       bmsstate[5];          // 电池状态数据（数据帧型号不同，需参考实际情况）。              
        unsigned long       reserve[3];           // 保留，目前不用。
      };
    };  // module dds_
  };  // module msg
};  // module unitree_hg

参数说明

  • version_high：电池软件版本高位
  • version_low：电池软件版本低位
  • fn：数据帧型号
  • cell_vol：单节电池电压（共40节）
  • bmsvoltage：电池电压信息，单位mV
    • bmsvoltage[0]：BAT电压信息，即电池组内部总电压
    • bmsvoltage[1]：PACK电压信息，即电池组对外输出的电压。
  • current：输出电流，单位mA。
  • soc：电量百分比。0%~100%
  • soh：电池健康度，0%~100%
  • temperature：电池温度，单位℃
  • cycle：循环数
  • manufactuere_dare：生产时间
  • bmsstate：电池状态数据
  • reserve：保留
